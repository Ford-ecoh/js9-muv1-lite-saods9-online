Annulus Photometry API

These synchronous browser APIs expose the scientific annulus calculation without opening Region Stats. Coordinates and radii are image pixels. The source aperture is the innermost radius; pixels out to the outermost radius provide the robust sky estimate.

Single annulus

const measurement = JS9.GetAnnulusPhotometry({
  x: 512.4,
  y: 498.1,
  sourceRadius: 8,
  skyOuterRadius: 18,
  calibration: { exposure: 60, zeroPoint: 25.13 }
}, { display: "JS9" });

Alternatively pass the id of an existing annulus region, or the region object returned by JS9.GetRegions():

const measurement = JS9.GetAnnulusPhotometry("region3", { display: "JS9" });

All displayed annuli

const batch = JS9.GetAllAnnulusPhotometry({
  calibration: { exposure: 60, zeroPoint: 25.13 }
}, { display: "JS9" });

Response

A successful response has ok: true and a versioned schema. Its top-level fields are:

region
Region id, center, and radii used for the calculation.
aperture
Source and sky radii in pixels, plus WCS pixel scale in arcsec/pixel when available.
background
Robust median background, RMS, and retained sky-pixel count.
photometry
Raw counts, background-subtracted flux, flux error, S/N, count rate, and FWHM.
magnitude
Instrumental magnitude, calibrated magnitude, error, zero point, and exposure.

Invalid input returns {ok:false, error:"..."}. A failed flux measurement is represented by null for affected derived values, never an infinite numeric value.

Viewer, regions, and events

JS9MuV1 also exposes compact, JSON-safe interfaces for a host application or a backend bridge. They do not expose FITS pixels; use the established JS9.GetImageData() API when pixel data is intentionally required.

// Current image metadata and visual state (pan, zoom, scale, colormap, WCS)
const state = JS9.GetViewerState({ display: "science" });

// Export/import region objects without saving a browser file
const saved = JS9.ExportRegionsJSON("all", { display: "science" });
JS9.ImportRegionsJSON(saved, { replace: true }, { display: "science" });

// React to a user edit or a programmatic pan/zoom/scale change
const token = JS9.Subscribe("regionschange", (event) => {
  console.log(event.payload.region);
}, { display: "science" });
JS9.Unsubscribe(token);

ExportRegionsJSON() returns the versioned js9muv1.regions/v1 payload. ImportRegionsJSON() accepts that payload or its regions array; replace:true first clears existing regions. Events are regionschange and viewchange, each with a versioned event envelope. The same events are also dispatched on window as js9muv1:regionschange and js9muv1:viewchange.
