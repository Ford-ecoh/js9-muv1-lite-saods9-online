Observation Preview API

Use this API when an observing system has finished writing a FITS file and needs a fast browser preview. It downloads the file, gives newer exposures priority, retries temporary failures, loads through the standard JS9 FITS path, and emits a compact quality summary.

const job = JS9.LoadObservationPreview({
  observationId: "obs-20261011-0042",
  status: "completed",
  url: "https://observatory.example/data/frame0042.fits.gz",
  filename: "frame0042.fits.gz"
}, {
  retries: 2,
  retryDelayMs: 1000,
  loadOptions: { scale: "zscale" }
}, { display: "science" });

A file whose status is not complete, completed, ready, or downloaded is not loaded. With the default latestWins:true, a request for a newer image aborts the older in-progress download for that display.

Status and events

JS9.Subscribe("observationpreview", (event) => {
  const job = event.payload;
  // queued, downloading, retrying, loading, ready, failed, or cancelled
  updateObservationUI(job.status, job.quality);
}, { display: "science" });

const current = JS9.GetObservationPreviewStatus({ display: "science" });

The same notifications are dispatched as the browser event js9muv1:observationpreview. Failed requests contain an error; retry attempts and cancellations are explicit, so a host system need not infer state from alert dialogs.

Quality summary

const qc = JS9.GetImageQualitySummary({
  saturationLevel: 60000
}, { display: "science" });

The result includes image dimensions, data minimum/maximum, zscale limits, WCS validity, and common FITS metadata: object, filter, exposure, observation time, telescope, and instrument. Supplying saturationLevel counts saturated pixels and returns their fraction. If a FITS SATURATE card exists, it is used automatically.
