UI visual QA checklist

This page is a repeatable release check for the Lite interface. Run it over HTTP, then open two viewer pages in the same browser tab or window and apply different UIConfig palettes.

  1. Open the viewer twice with distinct display ids in an embedding page.
  2. Open a floating plugin from each display and confirm its title, form controls, and text retain the owner display’s palette.
  3. Check Light, Dark, Midnight, High contrast, Compact, and Quick-look modes at 320px, 768px, and desktop widths.
  4. Check keyboard-only focus, touch scrolling, file triggers, color controls, Region Edit, and Region Stats.
